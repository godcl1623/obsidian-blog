# TypeScript·JavaScript 코드 규칙

- 절 머리에 TypeScript 전용이라고 적은 규칙은 TypeScript 파일에만 적용함

## 1. 타입과 상수

- TypeScript 전용
- 그 파일 안에서만 쓰는 타입과 상수(export하지 않는 것)는 쓰는 곳에 둠
- 타입은 추론을 우선하고, 추론으로 부족할 때만 선언함. 선언할 때는 인라인 객체 타입을 쓰지 않고, 객체는 interface로 씀. type은 유니언 등 타입 별칭이 필요할 때만 쓰고, 별칭 안의 객체 타입은 유니언 구성원일 때만 허용함(lint가 막음)
- 반환 타입: export 함수는 적음(lint가 막음). 파일 안에서만 쓰는 함수는 반환 모양이 갈리면(예: `Found | undefined`, 분기마다 다른 객체) 적고, 한 모양만 돌려주면 추론에 맡김

## 2. 함수

- `this` 바인딩을 쓰는 경우가 아니면 화살표 함수로 씀 (`const f = (x: T): R => ...`). `function` 선언은 쓰지 않음
- 화살표 함수는 끌어올려지지 않으므로, 쓰는 곳보다 위에 정의함
- 조건은 참일 때의 뜻을 나타내는 이름의 상수로 먼저 정의한 뒤 씀(예: `const closed = end !== -1`). 조건 자리에 식을 쓰지 않는 것은 lint가 막고, 이름이 뜻을 나타내는지는 검토가 봄
- 함수 본문은 인자를 가공한 값 → 변수·상수 → 안에서 쓸 함수 → return 순서로 씀
- 관심사가 바뀌는 곳에 빈 줄을 둠. 문장 종류에 따른 빈 줄(`return` 앞, if·반복문·switch·try와 블록으로 끝나는 문장 뒤, const·let 덩어리 앞뒤)은 lint가 막음

## 3. 함수 나누기

- 함수 하나가 여러 관심사를 판단하면 관심사마다 함수로 나누고, 나눈 함수를 차례로 부르는 함수로 합침
- 나눈 함수는 관심사별 파일에 둠. 합치는 함수는 부르는 순서만 담고 판단은 하지 않음
